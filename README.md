# Atomic Physics

This is a fork of [OxfordIonTrapGroup/atomic_physics](https://github.com/OxfordIonTrapGroup/atomic_physics), with extended functionality for optical transitions. This includes:

1. ``LaserDrive` class to handle spherical basis decomposition of polarizations and k-vectors for dipole and quadrupole transitions.
2. ``Atom.get_rabi_laser` function to calculate Rabi frequencies for dipole and quadrupole transitions.

Examples of the extended functionality can be found in ``examples/laser_transitions.ipynb`
